# Nitori

A Dart implementation for the [Satori Protocol](https://satori.chat/).

This is the umbrella package for the Nitori monorepo. It re-exports the
sub-packages:

- [nitori_core](https://pub.dev/packages/nitori_core) — protocol models and wire format
- [nitori_message](https://pub.dev/packages/nitori_message) — message element builder and parser
- [nitori_client](https://pub.dev/packages/nitori_client) — Satori client implementation
- [nitori_server](https://pub.dev/packages/nitori_server) — Satori server implementation

## Status

The project is still **working in progress**. Use at your own risk.
